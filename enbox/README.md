# Enbox Implementation Knowledge

This directory maps DWN semantics onto the current Enbox implementations.

Implementation pages should distinguish:

- current `enboxorg/enbox` TypeScript behaviour,
- current `enboxorg/enbox-rust-core` behaviour,
- known parity gaps,
- intentional divergence from the DWN draft.

Where possible, record the reviewed upstream commit and link the owning GitHub issue for non-parity behaviour.
